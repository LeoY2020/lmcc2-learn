    第 2 章 上机环境与工具链¶

    本章目标

    读完这一章，你能：认出 LMCC-IDE 里哪些功能在 2026 的三道题里真正有用、用离线文档查 API、用自动 Git 存档保命，并知道考场平台在哪些环节"替你把活儿干完了"。

    2.1　LMCC-IDE 是什么¶

    它是一个便携版的代码编辑器（基于 VS Code 改造，版本 0.1.1），把"写代码的环境"和"考场要用的模型环境"打包在一起：

    组件 版本 2026 三道题里怎么用
    Python 3.12 写 process_data(records)、写数据生成脚本、用分词器数 System Prompt 长度
    PyTorch 2.4.0 第二题不需要你写训练代码（平台提供），但可以用来本地试算向量/张量操作
    Transformers 4.55.0 用 Qwen 分词器数 Token（第一题 300 Token 限额靠它）、了解 chat template 与 thinking
    tokenizers 0.21.4 分词器底层实现
    numpy 1.26.4 注意是 1.x，不是 2.x

    考试怎么考

    官方说明：LMCC-IDE 预装的 Python 3.12、PyTorch 2.4.0、Transformers 4.55.0 与考试环境一致。你在本地算出来的 Token 数、跑出来的行为，基本就是考场上的行为。

    2.2　三道题在哪些环节由平台代劳¶

    与上一届"自己写 generate() 调模型"完全不同，2026 的很多环节是平台做好的：

    题目 平台负责 你负责
    第一题 加载 Qwen3-0.6B、拼 chat template、调用模型、分离思考与答案、统计 Token、评测 只写 System Prompt + 选 thinking
    第二题 GPU 调度、真实 LoRA 训练、保存与重载、评测 数据（train.jsonl）、清洗函数、训练参数
    第三题 提供项目、Agent（read_file / write_file / bash）、页面预览、用量统计、自动测试 只写对话（自然语言指令）

    坑

    三道题都不要写模型调用代码。第一题写了也没用（平台用自己的调用流程）；第二题训练代码由平台提供，你写训练脚本不会被执行；第三题连代码都不许你手改。把力气全部放在"规格"上：Prompt、数据、对话。

    2.3　文档中心：断网也能查 API¶

    按 Ctrl+Shift+P，输入 Documentation Center 打开。里面有：

    • 帮助与指南：LMCC-IDE 介绍、新增功能、常见问题、Local AI Copilot 指南；

    • 库文档：离线 PyTorch 2.4.0（HTML）与 Transformers 4.55.0（可搜索）官方文档。

    技巧

    第一题要卡 300 Token 限额，最靠谱的做法是用本地 Qwen 分词器真的数一遍，而不是数字数。用文档中心搜 AutoTokenizer 与 apply_chat_template，看它的调用方式，然后在终端里：len(tok(prompt_text)["input_ids"]) ——这就是平台视角的"Token 数"。

    2.4　自动 Git 存档：改坏了能回退¶

    LMCC-IDE 默认开启"保存即自动提交"（设置项 lmcc.autoGitCommit）。第二题的函数改崩了、第三题让 Agent 把项目改乱了，都可以在左侧「源代码管理」里回退到之前的版本。

    技巧

    把它当成"实验记录"：第二题每换一版数据或参数就保存一次并记下现场分数，很快就能看出"哪一版最好"。注意第三题：回退代码不会重置 Token 用量，用量一旦花掉就没了。

    2.5　资源监测、SSH 与环境急救¶

    • 资源监测：底栏实时显示 CPU、内存、GPU 占用（GPU 支持 NVIDIA 与部分昇腾型号）。第二题训练在平台侧跑，本地监测更多是看你自己脚本的开销。

    • SSH 远程：可连接部分 Linux x64/arm64 机器；连上后用目标机器的环境。

    • 环境急救：Ctrl+Shift+P → Python: Select Interpreter 确认解释器；异常时执行 Set LMCC Env 命令再重启 IDE；终端里验证：python -c "import torch, transformers; print(torch.__version__, transformers.__version__)" 应输出 2.4.0+cpu ... 4.55.0。

    2.6　考场平台的硬约束（务必记住）¶

    约束 说明
    不能联网 工作区不能联网；第三题的项目必须用提供的离线资源，页面不能调用外网。
    不能改的东西 模型、固定系统提示词（第二题）、公开测试、评分程序、题面与测试内容、启动脚本、许可证与来源说明。
    只能对话改代码 第三题：不得使用文件编辑器、命令行或外部工具直接改代码或测试内容。
    锁定与冻结 提交后作品与用量立即锁定；达到时间或预算上限时冻结当前作品。
    故障不背锅 平台侧训练故障会单独标记，不算模型答错；接口故障或用量未知时平台暂停并核对，不会按 0 用量处理。

    本章要记住的 4 件事

    • 本地环境 = 考试环境：Python 3.12 / PyTorch 2.4.0 / Transformers 4.55.0，可以用它数 Token、验行为。
    • 三道题都不需要你写模型调用代码：第一题只交 Prompt，第二题交数据 + 函数 + 参数，第三题只交对话成果。
    • 文档中心（Ctrl+Shift+P → Documentation Center）能离线查 PyTorch / Transformers 文档。
    • 保存即自动 Git 提交，改坏了能回退；但第三题的 Token 用量不可回退。
