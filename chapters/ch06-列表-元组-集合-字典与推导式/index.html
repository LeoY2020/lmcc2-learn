    第 6 章 列表、元组、集合、字典与推导式¶

    本章目标

    把 Python 的四种容器（列表、元组、集合、字典）和推导式、嵌套结构讲透：会创建、会增删改查、会遍历、会拷贝、会推导式，并且知道"什么时候该用哪一种"。

    6.1　列表（list）：有序、可变、最常用¶

    创建与访问¶

    v = [1, 2, 3]            # 字面量（类似 vector）
v = []                   # 空列表
v = list(range(5))       # [0,1,2,3,4]   由 range 生成
v = [0] * 4              # [0,0,0,0]     重复生成（注意：元素是可变对象时是同一引用）

v[0]        # 第一个元素        v[-1]   # 最后一个
v[1:3]      # 切片，左闭右开     v[:2]   # 前两个
v[::-1]     # 反转（返回新列表）  len(v)  # 长度

    坑

    [[]] * 3 得到的是"三个指向同一个空列表的引用"，改其中一个三个都会变；要三个独立列表得写 [[ ] for _ in range(3)]。

    增、删、改¶

    操作 说明 返回什么
    v.append(x) 末尾追加一个元素 None（原地修改）
    v.extend(iterable) 把另一个可迭代对象逐项追加 None
    v.insert(i, x) 在下标 i 处插入 None
    v.remove(x) 删除第一个等于 x 的元素 None；不存在抛 ValueError
    v.pop() / v.pop(i) 弹出末尾／指定下标 被弹出的元素
    del v[i] / del v[1:3] 按下标或切片删除 无
    v[i] = x 按下标赋值 无
    v.clear() 清空 None

    排序与查找¶

    v = [3, 1, 2]
v.sort()                 # 原地排序（改自己），返回 None
w = sorted(v)            # 返回排序后的新列表（不改 v）
v.sort(reverse=True)     # 降序
v.sort(key=lambda x: -x) # 自定义排序键
v.index(2)               # 第一次出现的下标（不存在抛 ValueError）
v.count(2)               # 出现次数
2 in v                   # 是否包含

    技巧

    上面排序里的 key=... 与 lambda 是什么，见第 7.6 节——那里从零解释了"把函数当值用"这件事，C++ 里没学 lambda 也不影响。

    坑

    v = v.sort() 是经典错误：sort() 原地排序并返回 None，这一行会把 v 变成 None。要么写 v.sort()，要么写 v = sorted(v)。

    遍历与"边遍历边删"¶

    for x in v:              # 直接取值
    print(x)
for i, x in enumerate(v, 1):    # 同时要下标（从 1 开始编号）
    print(i, x)

# 错误示范：边遍历边删会跳元素
for x in v:
    if x % 2 == 0:
        v.remove(x)      # ✗ 不要这样写

# 正确做法 1：构造新列表
v = [x for x in v if x % 2 != 0]
# 正确做法 2：倒序遍历删除
for i in range(len(v) - 1, -1, -1):
    if v[i] % 2 == 0:
        del v[i]
    C++ Python
    vector v; v = []
    v.push_back(x) v.append(x)
    v.size() len(v)
    v.pop_back() v.pop()
    sort(v.begin(), v.end()) v.sort()
    v.insert(v.begin()+i, x) v.insert(i, x)

    6.2　元组（tuple）：不可变的"打包"¶

    t = (1, 2, 3)
t2 = 1, 2, 3          # 括号可以省略，逗号才是关键
one = (5,)            # 单个元素必须加逗号，否则 (5) 只是整数 5
empty = ()
t[0]                  # 可以下标访问
# t[0] = 9            # ✗ 报错：元组不可修改
len(t)                # 3

    解包：元组最好用的地方¶

    a, b = 1, 2
a, b = b, a                      # 交换，不需要临时变量
x, y = (3, 4)                    # 解包
first, *rest = [1, 2, 3, 4]      # first=1, rest=[2,3,4]
head, *mid, tail = [1, 2, 3, 4]  # head=1, mid=[2,3], tail=4

def min_max(nums):
    return min(nums), max(nums)  # 实际返回一个元组

lo, hi = min_max([3, 1, 2])      # lo=1, hi=3

for i, poem in enumerate(poems, 1):   # 也是解包
    print(i, poem)

    什么时候用元组¶

    • 固定不变的一组值：坐标 (x, y)、RGB 颜色、日期。

    • 函数返回多个值：return code, message。

    • 当作字典的键（列表不能当键，因为列表可变、不可哈希）。

    • 需要"防止被误改"时——元组不可变，相当于一种"只读约定"。

    技巧

    考试里最常见的元组用法就两处：for i, x in enumerate(...) 与排序键 sorted(items, key=lambda t: (t[1], t[0]))。把这两句写熟就够了。

    6.3　集合（set）：去重、快速查找、集合运算¶

    s = {1, 2, 3}            # 字面量
s = set()                # 空集合必须写 set()，因为 {} 是空字典！
s = set([1, 1, 2])       # {1, 2}  去重
s.add(4)                 # 添加
s.discard(1)             # 删除（不存在也不报错）
s.remove(1)              # 删除（不存在抛 KeyError）
2 in s                   # 成员判断：平均 O(1)，比列表快得多
len(s)

    集合运算¶

    运算 符号 含义
    并集 a \| b 或 a.union(b) 属于 a 或属于 b 的元素
    交集 a & b 或 a.intersection(b) 同时属于两者的元素
    差集 a - b 在 a 但不在 b
    对称差 a ^ b 只属于其中一个
    子集判断 `a 3 for w in words) # 只要有一个满足就返回 True
    all_ok = all(ch in "()" for ch in seq) # 是否全部满足 
    | 写法 | 结果 | 什么时候用 |
|---|---|---|
| `[f(x) for x in v]` | 新列表（立刻算完） | 需要保留结果 |
| `(f(x) for x in v)` | 生成器（用到才算） | 只喂给 `sum/any/all/max` 等函数，省内存 |
| `{k: v for ...}` | 新字典 | 建映射表 |
| `{f(x) for x in v}` | 新集合 | 去重 |

!!! warning "坑"
    推导式里不要写有副作用的东西（append、print、改外部变量）。它适合"由旧造新"，不适合"做事"。超过一行或者条件超过两个，就改回普通 for 循环——可读性比短更重要。

### 去重且保持原顺序（考场常用）

```python
seen, out = set(), []
for x in data:
    if x in seen:
        continue
    seen.add(x)
    out.append(x)

# 等价写法：字典保序 + dict.fromkeys
out = list(dict.fromkeys(data))

    6.6　嵌套结构：把 JSON 搬进内存¶

    考试里的数据几乎都是"列表套字典"或"字典套列表"。看懂嵌套的关键是一层一层往下取。

    records = [
    {"sequence": "()()", "valid": "YES", "tags": ["连续", "短"]},
    {"sequence": ")( ",  "valid": "yes", "tags": []},
]

records[0]["sequence"]              # "()()"        列表 → 字典 → 值
records[0]["tags"][1]               # "短"          列表 → 字典 → 列表 → 值
for r in records:                   # 遍历外层列表
    for k, v in r.items():          # 遍历内层字典
        print(k, v)

    安全访问嵌套数据¶

    def get_score(record):
    if not isinstance(record, dict):
        return None
    seq = record.get("sequence")
    tags = record.get("tags")
    if not isinstance(seq, str):
        return None
    if not isinstance(tags, list):
        tags = []
    return len(seq), tags

    构造嵌套结果¶

    result = [
    {"input": "序列：" + r["sequence"], "output": "[Valid]: " + r["valid"].strip().upper()}
    for r in records
]
    JSON Python C++ 类比
    对象 {...} dict map
    数组 [...] list vector
    字符串 / 数字 / 布尔 / null str / int,float / bool / None 基本类型 / nullptr

    坑

    嵌套结构里最危险的操作是"先把字典放进结果列表，之后再改这个字典"——因为放进去的是引用，外面一改，列表里的内容也跟着变。要放进结果里的记录就新建一个字典（如上面的 {"input": ..., "output": ...}）。

    6.7　引用、浅拷贝与深拷贝¶

    a = [1, 2, 3]
b = a                    # b 是 a 的别名（同一对象），不是拷贝
b.append(4); print(a)    # [1,2,3,4]  ← a 也变了

c = a[:]                 # 浅拷贝（切片）
d = a.copy()             # 浅拷贝（等价）
e = list(a)              # 浅拷贝（等价）

import copy
f = copy.deepcopy(a)     # 深拷贝：连嵌套的子对象一起复制
    操作 顶层是否独立 嵌套子对象是否独立
    b = a 否（别名） 否
    a[:] / a.copy() 是 否（共享子对象）
    copy.deepcopy(a) 是 是 
    nested = [[1], [2]]
shallow = nested[:]
shallow[0].append(9)
print(nested)            # [[1, 9], [2]]  ← 浅拷贝没能隔离内层

compare = (a == b)       # 值是否相等（逐元素比较）
same = (a is b)          # 是否是同一个对象

    坑

    函数参数也是"传引用"：把列表或字典传进函数，函数内修改会影响到外面。如果不想影响调用方，函数内部先复制（data = list(data) 或 copy.deepcopy）。第二题的清洗函数要保证"每次调用都从零开始"，正是这个道理。

    6.8　四种容器怎么选¶

    容器 有序？ 可变？ 最适合
    list 是 是 有序集合、需要按下标访问、结果列表
    tuple 是 否 固定的一组值、多返回值、字典的键
    set 否 是 去重、快速成员判断、集合运算
    dict 是（插入序） 是 键值映射、一条记录、计数与分组

    • 用一行推导式取出 [1..10] 中的所有奇数。

    • 用一行代码把 ["a", "b", "a", "c"] 去重且保持原顺序。

    • 写一个函数，统计 records 里 valid 为 YES 的条数（记录是 dict，可能缺字段）。

    # 参考答案
print(sorted([3, 1, 2]), [3, 1, 2])                 # [1, 2, 3] [3, 1, 2]
odds = [x for x in range(1, 11) if x % 2]           # [1,3,5,7,9]
uniq = list(dict.fromkeys(["a", "b", "a", "c"]))    # ['a','b','c']
x, y = y, x
from collections import Counter
print(Counter("banana"))                            # Counter({'a':3,'n':2,'b':1})
print(sorted([("A", 3), ("B", 1)], key=lambda t: t[1]))
d = {"a": [1, 2]}; d["a"].append(3)                 # 只改 "a" 指向的那个列表
def count_yes(records):
    return sum(1 for r in records
               if isinstance(r, dict) and r.get("valid", "").strip().upper() == "YES")

    本章要记住的 6 件事

    • 列表可变、元组不可变；sort() 原地排序返回 None，sorted() 返回新列表。
    • 元组用于"固定的一组值 + 解包"：a, b = b, a、for i, x in enumerate(v, 1)。
    • 集合用于去重与快速查找；空集合写 set()；去重保序用 dict.fromkeys 或 seen 集合。
    • 字典是"一条记录"：取值用 d[k]、安全取值用 d.get(k, 默认)、遍历用 items()。
    • 推导式由旧造新；只喂给 sum/any/all 时用生成器表达式省内存；有副作用就别用推导式。
    • 赋值是别名不是拷贝；浅拷贝不隔离嵌套子对象，嵌套结构要用 copy.deepcopy。
