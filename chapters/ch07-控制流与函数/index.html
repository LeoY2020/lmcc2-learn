    第 7 章 控制流与函数¶

    本章目标

    掌握 if / for / while 的 Python 写法、函数定义与参数规则、异常与断言，能写出结构清晰、可自测的小函数。

    7.1　if / elif / else¶

    score = 85
if score >= 90:
    print("优秀")
elif score >= 60:          # 相当于 else if
    print("及格")
else:
    print("不及格")
    C++ Python
    if (a && b) { } else if (c) { } if a and b: 换行缩进，elif c:
    switch (x) { case 1: ... } 链式 if/elif（3.10 以后也有 match，但考试里用 if 更清晰）
    a > b ? a : b a if a > b else b

    真值判断：Python 里以下值都算"假"——False、None、0、0.0、""（空串）、[]（空列表）、{}（空字典）、set()。所以可以简写：

    if not records:          # 等价于 records == [] 或 records is None 之类
    print("没有数据")
if text:                 # 非空字符串
    print("有内容")

    坑

    简化写法很爽，但在"跳过脏数据"的场景里要小心：if not seq: continue 会把长度 0 的串过滤掉（正确），但如果你本意是"只过滤 None"，写成 if not s 会把空串一起过滤。规格怎么要求，你就怎么写。

    7.2　while、break、continue¶

    i = 0
while i  max_len:
        return None
    return s

print(normalize("  ab  "))          # ab
print(normalize("  ab  ", 1))       # None
print(normalize("  ab  ", max_len=1))   # 关键字参数，语义更清楚

    • 参数可以有默认值（max_len=12），调用时可以省略或按名字传。

    • 没有类型标注也可以，但加上更清楚：def f(raw: str) -> bool:（第 10.9 节）。

    • 没有 return 的函数返回 None；return 可以返回多个值（元组）。

    坑

    绝不要用可变对象当默认值：def f(acc=[]) 的默认列表只在函数定义时创建一次，多次调用会累积。正确写法是 def f(acc=None)，在函数内 if acc is None: acc = []。

    7.5　作用域¶

    count = 0                  # 模块级（全局）

def bump():
    global count            # 想在函数内改全局变量必须声明（不推荐）
    count += 1

def local_demo():
    x = 5                   # 局部变量，函数外看不见
    return x

    Python 没有"块级作用域"：if、for 里定义的变量在块外仍然存在。函数才有自己的作用域。写第二题的原则：只用局部变量，每次调用从零开始，不依赖任何外部状态。

    7.6　把函数当值用：匿名函数 lambda 与排序键¶

    Python 里函数也是一种值：可以赋给变量、当参数传给别的函数、当返回值返回。理解这一点，才能看懂 sorted(v, key=...) 这类写法。

    1) 先看"函数是值"这件事¶

    def double(x):
    return x * 2

f = double          # 注意：没有括号，是把函数本身赋给 f
print(f(3))         # 6
print(double(3))    # 6（两种写法等价）

def apply(func, value):     # 把函数当参数收进来
    return func(value)

print(apply(double, 5))     # 10

    既然函数能当参数，就可以写"做某件事的通用函数"——比如排序时告诉它"按什么排序"。

    2) lambda 是什么¶

    lambda 是匿名函数：一种只写"参数 + 一个表达式"的临时小函数，不用起名字。写法是：

    lambda 参数: 表达式        # 冒号后面只能是一个表达式，不能写多行语句
    用 def 写 用 lambda 写
    def square(x):
    return x * x square = lambda x: x * x
    def add(a, b):
    return a + b add = lambda a, b: a + b

    两者功能一样，但 def 版本能写多行、能加注释与文档、有名字（便于调试）。lambda 的唯一优势是"短"：用在只需要写一次、立刻就要用的地方。

    print((lambda x: x * x)(5))     # 25：定义完立刻调用（很少这么写）

    3) 主要用途：给排序/取最值指定"规则"¶

    sorted(v, key=函数) 的含义是：先把每个元素交给这个函数，得到一个"排序依据"，再按依据排序。原元素不会被改变。

    items = [("A", 3), ("B", 1), ("C", 2)]

# 不写 key：按元素本身比较（元组会先比第一项，再比第二项）
print(sorted(items))                      # [('A',3), ('B',1), ('C',2)]  ← 按字母排

# 写 key：按元组第二个元素排
print(sorted(items, key=lambda t: t[1]))  # [('B',1), ('C',2), ('A',3)]

# 降序：给依据取负（数字适用），或用 reverse=True
print(sorted(items, key=lambda t: t[1], reverse=True))   # [('A',3), ('C',2), ('B',1)]

# 多关键字：返回一个元组，先比第一个，相同再比第二个
print(sorted(items, key=lambda t: (t[1], t[0])))

    把 key=lambda t: t[1] 读成人话就是："对于每个元素 t，用 t[1] 作为排序依据"。

    想做什么 写法
    按字符串长度排序 sorted(words, key=len)
    按字典某个字段排序 sorted(rows, key=lambda r: r["score"])
    按绝对值排序 sorted(nums, key=abs)
    找最大值/最小值所在的那条 max(rows, key=lambda r: r["score"])
    不改变原列表 sorted(...)；要原地排序用 v.sort(key=...)

    4) 不想用 lambda 也有三种写法¶

    # 写法一：先定义具名函数，再传进去（最易读）
def score_of(r):
    return r["score"]
print(sorted(rows, key=score_of))

# 写法二：用内置函数当 key（够用时优先）
print(sorted(words, key=len))

# 写法三：取固定位置用 operator.itemgetter（比 lambda 更快更短）
from operator import itemgetter
print(sorted(items, key=itemgetter(1)))      # 等价于 key=lambda t: t[1]

    技巧

    考场上推荐顺序：内置函数（len/abs）→ itemgetter → lambda。lambda 只在"只写一次、一句话能说清"时用；一旦要写判断或多个步骤，就改回 def 函数，可读性更好。

    5) 三个容易踩的坑¶

    坑

    ① lambda 里不能写语句：赋值、print、if: 这些都不行，只能写一个表达式（三元表达式 a if c else b 可以）。 ② 不要给 lambda 起名字再用：f = lambda x: x * 2 之后到处调用 f，不如直接写 def f(x)；后者在报错信息里能显示函数名。 ③ 循环里的延迟绑定：[lambda: i for i in range(3)] 里的 i 是"取值时才查找"，三个函数最后都会得到 2。要固定住就写 [lambda i=i: i for i in range(3)]（考试几乎用不到，知道有这回事即可）。

    6) 练习¶

    • 把 [("apple", 3), ("pear", 1), ("fig", 2)] 按第二个元素升序排序。

    • 按字符串长度从长到短排列 ["ccc", "a", "bb"]。

    • 找出 [{"name": "A", "s": 80}, {"name": "B", "s": 95}] 中分数最高的一条。

    • 用 def 函数改写第 1 题，不使用 lambda。

    # 参考答案
data = [("apple", 3), ("pear", 1), ("fig", 2)]
print(sorted(data, key=lambda t: t[1]))                 # [('pear',1), ('fig',2), ('apple',3)]
print(sorted(["ccc", "a", "bb"], key=len, reverse=True))  # ['ccc','bb','a']
rows = [{"name": "A", "s": 80}, {"name": "B", "s": 95}]
print(max(rows, key=lambda r: r["s"]))                  # {'name': 'B', 's': 95}

def second(t):
    return t[1]
print(sorted(data, key=second))

    7.7　异常：raise 与 try¶

    def check(records):
    if not isinstance(records, list):
        raise ValueError("records 必须是列表")      # 主动抛出
    return True

# 捕获
try:
    check(None)
except ValueError as e:
    print("捕获到：", e)          # 捕获到： records 必须是列表
finally:
    print("无论如何都会执行")
    常见异常 什么时候出现
    ValueError 值不合法（如 int("abc")、规格要求你主动抛）
    TypeError 类型不对（如 "a" + 1、对 None 取下标）
    KeyError 字典没有这个键
    IndexError 列表下标越界
    AttributeError 对象没有这个属性（如对整数调 .strip()）
    SyntaxError / IndentationError 语法或缩进错误

    坑

    不要用 try/except 把一大段逻辑包起来"防止报错"——那会把"该跳过一条"变成"整批异常"或"静默吞错"。规格说跳过就 continue，说抛错就 raise。异常处理是规格的一部分，不是保险丝。

    7.8　assert：把测试点写进代码¶

    def normalize(raw):
    if not isinstance(raw, str):
        return None
    s = raw.strip().upper()
    return s if s in ("YES", "NO") else None

assert normalize(" yes ") == "YES"
assert normalize("MAYBE") is None
assert normalize(None) is None
print("全部通过")

    assert 条件：条件为假时抛 AssertionError。这是"自测"最省事的形式——把官方的公开测试点写成断言，改完代码跑一遍就知道有没有坏。

    7.9　类型注解与 docstring¶

    def process_data(records: list) -> list:
    """
    把原始记录清洗为 {"input": ..., "output": ...} 的列表。

    参数:
        records: 原始记录列表，元素通常是 dict
    返回:
        清洗后的列表，保持原始顺序
    """
    ...

    类型注解不影响运行（Python 不强制检查），但能让代码自解释，也方便别人看懂。docstring 就是函数第一个字符串，IDE 会自动显示为提示。

    7.10　练习¶

    • 写函数 is_valid_seq(s)：判断括号序列是否合法（前缀条件 + 总数条件）。

    • 写函数 normalize(raw, max_len=12)：删除全部空白；长度必须在 2～max_len；只允许半角括号；不合格返回 None。（提示：需要 import re）

    • 给上面两个函数各写 3 条 assert。

    • 解释 def f(acc=[]) 的隐患，并给出正确写法。

    # 参考答案
import re

def is_valid_seq(s):
    bal = 0
    for ch in s:
        bal += 1 if ch == "(" else -1
        if bal < 0:
            return False
    return bal == 0

def normalize(raw, max_len=12):
    if not isinstance(raw, str):
        return None
    seq = re.sub(r"\s+", "", raw)
    if not (2 <= len(seq) <= max_len):
        return None
    if re.fullmatch(r"[()]+", seq) is None:
        return None
    return seq

assert is_valid_seq("()()") is True
assert is_valid_seq(")(") is False
assert is_valid_seq("(()") is False
assert normalize(" ( ( ) ) ") == "(())"
assert normalize("(a)") is None
assert normalize(None) is None
print("全部通过")

    本章要记住的 5 件事

    • if/elif/else、for ... in range(...)、while 都要冒号加缩进；range 左闭右开。
    • 函数用 def，可带默认参数；默认值不要用可变对象。
    • 逻辑运算写 and/or/not；真值判断里空串、空列表、0、None 都是假。
    • raise ValueError(...) 主动报错；try/except 只在确实需要时使用。
    • assert 是自测的最快方式：把测试点写成断言。
