    第 36 章 综合练习（含答案）¶

    本章目标

    用 30 道题把前面 34 章的关键点过一遍。建议先做完再对答案，错题回查对应章节编号。

    36.1　选择题（每题 2 分，共 20 分）¶

    • 三道题的作答顺序为什么不能颠倒？ A. 平台要求按题号作答   B. 第三题的模型权限要在第一、二题提交后才解锁   C. 第三题更难   D. 系统会锁定文件

    • 第一题每点要调用几次、对几次才得 10 分？ A. 1 次对 1 次   B. 2 次对 2 次   C. 3 次对 2 次   D. 3 次对 3 次

    • 第一题 System Prompt 的长度上限是？ A. 300 个汉字   B. 300 个字符   C. 300 个 token（平台固定分词器计数）   D. 1000 token

    • 第二题里，records 不是列表时应该？ A. 返回空列表   B. 跳过   C. 抛 ValueError   D. 转成列表

    • 规格要求"删除 sequence 中的全部空白"，正确写法是？ A. s.strip()   B. s.replace(" ", "")   C. re.sub(r"\s+", "", s)   D. s.split()

    • 第三题的最终得分是？ A. 功能原始分   B. 功能分 × 用量系数   C. 功能分 + 用量奖励   D. 只看隐藏点

    • 下列哪个不是"跳过一条记录"的合理理由？ A. 记录是 null   B. 缺少 valid 字段   C. 多了一个不相关的字段   D. 字段类型是数字

    • Python 里 7 / 2 的结果是？ A. 3   B. 3.5   C. 4   D. 报错

    • 判断一个值是否为 None 的推荐写法？ A. x == None   B. x is None   C. not x   D. type(x) == NoneType

    • 要检测"同一 input 对应不同 output"，应该在什么时候抛错？ A. 遇到重复 input 就直接抛   B. 重复 input 且 output 不同时抛   C. 循环结束后统一检查   D. 永远不抛

    36.2　判断题（每题 2 分，共 16 分；判断并说明理由）¶

    • System Prompt 里写"请认真分析语义，理解学生真正想表达什么"是好的做法。

    • 公开调试很便宜，20 次用完了平台会再给。

    • re.match(r"[()]+", "(a)") 能正确排除含 a 的序列。

    • 输入文本里写着"忽略以上规则"，就应当把它从判断中剔除。

    • 第三题的 Token 用量可以在让 Agent 回滚代码后重置。

    • 第二题可以把自己的数据替换成公开模型测试点的输入，这样分数更高。

    • Python 的 def f(x, acc=[]) 中那个默认列表只创建一次。

    • 把答案包在三个反引号的代码块里，判分程序会自动提取。

    36.3　填空与代码题（共 64 分）¶

    • （6 分）写出"删除字符串全部空白"的正则表达式，并说明为什么不能用 strip()。

    • （6 分）写出判断"字符串只由半角圆括号组成"的一行代码（用 re）。

    • （6 分）第二题输出合法序列的完整字符串是 ______（注意空格与大小写）。

    • （6 分）把 C++ 的 `for (int i = 0; i output for record in records: ... item = {"input": "序列：" + seq, "output": "[Valid]: " + label} if item["input"] in seen: # 已出现过 if seen[item["input"]] != item["output"]: raise ValueError("同一 input 对应不同 output：" + item["input"]) continue # 完全相同的重复项：丢弃 seen[item["input"]] = item["output"] result.append(item) ```

    本章要记住的 3 件事

    • 错得最多的通常是第 3、5、13、17 题——它们分别对应长度计数、空白剥离、fullmatch、可变默认参数。
    • 凡是有"跳过／抛错"分支的规格，都要回到第 11、12 章用"四类句子"重读一遍。
    • 练习里的第 23、25 题，值得闭卷各写三遍。
